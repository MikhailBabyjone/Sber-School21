Как сделать своё начальное поле
================================
1. Открой 06_custom.txt в редакторе.
2. Там сетка 25 строк по 80 символов.
3. 0 = мёртвая клетка, 1 = живая.
4. Расставь единицы как хочешь (не меняй число строк/столбцов).
5. Запуск:
   ./game_of_life < 06_custom.txt

Пример глайдера (фрагмент, не весь файл):
010
001
111
